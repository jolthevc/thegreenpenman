# Publication and approvals

## Exact-copy governance
- On-image sentence and caption are distinct approved fields.
- Never silently rewrite the approved line during rendering, captioning or export.
- If an illustration generator changes a word, it is a failed text render until corrected.
- Version any revisions, ideally using git diffs.
- Only user or clearly delegated approver can change approval flags.

## Standard states
`idea` → `copy_draft` → `copy_approved` → `art_draft` → `art_approved` → `package_ready` → `published`.
`retired` is a terminal/non-active state. Return to draft on meaningful changes.

## Attribution / rights
- Use original sayings where possible, and verify before making originality/attribution claims.
- Traditional proverbs may be used if the source and wording are documented.
- Copyrighted creator artwork is not a production style reference to trace.
- Keep commercial font licensing and stock licensing legal. Do not commit or share font files.

## Platform/export
- Default: 4:5 1080x1350 PNG, clean image without Instagram UI.
- Text safe margins tested at feed thumbnail size.
- Plain-caption body, with a strong practical explanation rather than overlong essays.
- No surprise watermark, fabricated brand handle or metadata.
- Reels with subtle movement/music are future tests; not default or automatic.

## Review before posting
Confirm exact ID, actual final image file, on-image transcription, final caption, account, desired publish action and approvals. Publishing is a separate externally authorized task, not implied by creative signoff.
